# EP001 别装了

## EP001-SC001 内外 · 出租屋门厅/客厅 · 夏末夜

巷子深处，林野压低棒球帽檐走到独栋小楼门前，钥匙插锁，先扫一眼身后空无一人的巷子。

[OS] 两个男生的争论声从巷口飘来：动物园的狮子喷火烧死了人——视频删了你看个屁。

林野推开门缝。潮湿暖风扑面。他按亮灯——

整间客厅被密密麻麻的绿色藤蔓吞没——沙发、茶几、吊灯全裹在里面，像一屋子绿油油的蛆。灯光亮起的瞬间，所有叶片齐刷刷转向门口。

林野嘴角抽了一下，放下书包，从里面摸出实验记录本翻开。

[画面文字] 一月七日常春藤变异 / 一月八日怕火 / 一月九日怕电恢复快 / 一月十日会模仿思维

林野合上本子，望向墙角那盆花盆已碎、根茎扎进地板缝的常春藤。主茎上布满刀砍、火烧、电击的旧疤。

林野（语气平淡）：别装了。你能听懂。

藤蔓静止两秒——骤然暴起！三根主蔓从三个方向抽来，缠腿、绞颈，一根细根扎进他小腿吸血。

林野不躲，反手抽出一把杀猪刀斩向脚踝藤蔓——刀锋撞上一层暗红光膜，虎口发麻，刀身崩出裂纹。

林野：血气护盾。吸了我的血做盾，能扛几次？

绞颈的藤蔓收紧。林野眼前发黑——他猛地咬舌尖，血腥味炸开的一瞬清醒，掏出玻璃瓶弹开瓶塞，整瓶浓硫酸泼向墙角根茎！

[SFX] 嘶——白烟爆起。

根茎发黑碳化，藤蔓疯狂收缩。林野挣脱，小腿两排血洞，裤管湿了一片。他看都没看，摸出自制酒精喷火器，打火——两米火舌横扫满屋。

三分钟后，只剩焦糊味和满地黑灰。林野站在灰烬中间，衣服烧了几个洞，头发燎焦一撮，表情平静得像刚做完一次化学实验。

林野：浓硫酸有用。跟实验结论一致。

## EP001-SC002 内 · 出租屋客厅 · 同夜

机械音在林野耳边响起，半透明蓝色面板在空中亮起。

[画面文字] 消灭玩家 DQ35***1234 / 资格转移程序启动 / LV1·经验0/100 / 欢迎来到——超凡杀场

林野（对着空气）：所以，我杀的不是植物，是玩家？植物也能当玩家？

面板闪出一行「是。种族不限。」

林野听完这一整段播报。

林野：中二味冲天。

他弯腰从灰堆里捡起一只藤蔓编的手镯——黑棕色，缀着五颗嫩绿小芽。面板同步亮出属性。

[画面文字] 灵藤手镯·精良 / +1体质 / 破幻境 / 灵力催藤 / 血液强化

林野把手镯戴上左手腕。心念一动，一颗芽疯长成两米长藤蔓，蛇一样绕着他的手臂转圈。

林野：还行。

藤蔓缩回。面板忽然变红，弹出任务界面，倒计时开始跳动。

[画面文字] 试炼任务·捉迷藏 / 目标：天亮前不离开房屋且保持存活 / 39分钟后开始·不可拒绝 / 失败惩罚：剥夺资格，并抹除

林野盯着「抹除」两个字看了三秒，一言不发，转身拉开柜子——砍刀、反曲弓、精钢箭、消防斧、捕兽夹、防刺背心、电锯。他把武器一件件分放到屋里顺手的位置。

[SFX] 门铃响了。

林野动作停住。夜里十点多。他走到猫眼前——门外路灯下站着一个圆脸男生，黑框眼镜，浅蓝卫衣，手里的塑料袋被攥得皱巴巴。

[画面文字] 倒计时 34:00

林野拉开门一条缝。

钱多多（声音发抖）：林、林野！你可算开门了——张老师让我给你送作业……

林野看他一眼，又看他身后漆黑的巷子。

林野：进来。外面不安全。

他一把将人拽进门，反手落锁。
