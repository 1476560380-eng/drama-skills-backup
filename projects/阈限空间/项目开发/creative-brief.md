# 短剧创作简报 · 阈限空间

## 1. 项目意图

- **暂定名**：阈限空间
- **一句原始想法**：普通高中生林野把家里那株变异常春藤做了一周实验后反杀它，被迫成为「超凡杀场」系统的玩家，在不可拒绝的任务里活命并变强
- **这次要完成的工作**：分集规划（本轮仅 EP1–EP2，改编自原著第一章）
- **来源材料**：`输入/第一章-常春藤.md`（约7600字，全量已拆解，见 `项目开发/source-analysis/`）
- **不可更改的来源事实**（落点=EP1/EP2 的可见载体）：
  - 常春藤有智能、会先动手（三蔓暴起绞杀）→ EP1，藤蔓袭击动作
  - 林野以实验思维战斗（记录本+硫酸/火验证）→ EP1，记录本特写+验证台词「浓硫酸有用，跟实验结论一致」
  - 杀的是「玩家」，资格跨物种转移 → EP1，系统面板 UI「消灭玩家 DQ35***1234 / 资格转移」
  - 任务规则「不离开房屋且存活」+失败=抹除 → EP1 尾，任务面板特写
  - 「任务没说不许打」的规则博弈 → EP2，林野自语台词
  - 钱多多怂但可用（被迫下楼上、扔布条成功）→ EP2，下楼捡布条整段行动
  - SSS 评级+房屋无损复原 → EP2 尾，结算 UI+复原对比镜头
  - 老槐树下窥视者+【第2天】 → EP2 尾，末镜反光+角标（延后揭示身份）
  - 世界异变旁证（喷火狮子/黄鼠狼/体制加班）→ EP2，钱多多证言对白（压缩为两句）
- **允许改编/探索的范围**：叙述顺序、场景压缩、配角戏份增减、系统播报的视觉化方式、台词口语化
- **原著没有、本轮新增的内容**：
  - 无新增人物/场景/对手。EP1 冷开直接取原著开场（开门见藤蔓客厅），非后文提前，无 `cold_open`/`add` 登记

## 2. 创作者契约

- **希望观众反复获得的体验**：规则博弈的智斗爽感 + 恐怖-喜剧交替的情绪过山车 + 系统奖励兑现的升级快感
- **不希望作品变成什么**：纯恐怖惊吓堆砌；拖节奏的设定说明书
- **主题张力**：理性掌控 ↔ 不可知的系统规则
- **语气与尺度**：都市怪谈，恐怖与黑色幽默并行，暴力不血腥展示（火烧怪物用剪影/黑气处理）
- **结局承诺或禁区**：开放（原著仅一章，长线未定）
- **内容边界**：不出现对人的直接血腥特写

## 3. 形式与制作边界

- **主要语言**：中文对白（川渝方言色彩），关键帧正文英文
- **画幅/观看场景**：16:9 横屏
- **单集与系列形式**：90 秒 × 10 集（本轮 EP1–EP2）
- **可用角色与场景规模**：核心 2 人 + 单元怪 3 只；主场景 1 栋两层小楼（内景为主）+ 巷子外景
- **难以承受的制作元素**：三怪同框长镜头（分镜拆单怪特写）；大规模群戏；日间城市外景
- **必须保留的视觉/声音特征**：系统 UI 面板悬浮视觉；藤蔓生物运动质感；林野的「平静脸」表演基调

## 4. 戏剧承诺（工作版）

- **焦点人物**：林野（高中生实验狂，被迫成为玩家）
- **当前追求**：搞懂系统规则，在不可拒绝的任务里活到天亮
- **昂贵阻力**：超凡杀场系统——随机派发不可拒绝任务、失败即抹除；任务怪物随升级越来越强
- **独特矛盾**：林野的实验验证式打法（先试再杀）每次都暴露在「样本没试完就先动手」的死亡风险里；冷静理性是他活命的本钱，也是他把钱多多拖下水的原因
- **反复回报**：每集一个任务闭环=规则破解的智斗爽 + 装备/等级兑现 + 搭档喜剧
- **终止性转变**：长线未定（原著仅一章）；候选方向=系统真容揭示/玩家资格可否放弃

**一句工作陈述**：一个把怪物当实验对象的冷血高中生，被系统选中后不得不用同一套实验方法在死亡任务里通关，顺手捡了一个怂包同学当观测者搭档。

## 5. 方向候选与选择

方向已由原著+创作者定死（规则怪谈+超凡游戏流），只记录选定方向：

- **选定**：忠于原著第一章的单任务闭环结构（EP1 反杀+系统降临 / EP2 守家战+搭档组建）
- **选择理由**：原著第一章自带完整「危机→备战→决战→结算」弧线与双主角相遇，screen_ready 密度极高，无需重构
- **明确拒绝的方向**：改动林野冷血理性人设；提前揭穿老槐树窥视者身份；把钱多多改成胆大配角
- **仍待确认的分支**：EP3+ 走向（等原著后续章节）

## 6. 核心人物与关系压力

### 林野

- 当前目标：活过今晚的「捉迷藏」任务
- 保护对象：自己的命；被动卷入的钱多多（不承认）
- 被捍卫的信念：一切异常皆可实验、可验证、可控制
- 前史成因：独居、自己做「友好实验交流」（原著未展开，保留为暗线）
- 惯常策略：记录→小样本测试→弱点验证→高效清除
- 策略盲区与代价：把活人当变量（钱多多下楼捡布条）；对系统本身零认知
- 可用筹码：武器库、化学知识、灵藤手镯
- 底线：不主动害死无辜
- 可能改变策略的事实：任务规则出现他验证不了的例外

### 钱多多

- 当前目标：活着回家见妈
- 被捍卫的信念：听话、当好人就能平安
- 惯常策略：讨好、跟随强者、碎碎念自我安抚
- 盲区：胆小但关键时刻没掉链子（原著证据 L303）
- 可能改变策略的事实：观测者权限让他第一次「看见」别人看不见的规则

### 核心关系：林野 ↔ 钱多多

- 林野需要钱多多：劳动力+普通人视角的验证样本（嘴上不承认是保护）
- 钱多多需要林野：唯一的 survival anchor
- 不平衡：能力完全不对等；观测者权限建立后从「拖油瓶」变「有用途的搭档」
- 可能位移：钱多多从被保护者成长为主动参与者（EP2 已埋：他主动要求跟随下楼）

## 7. 叙事切入窗口与首集入口

- **切入前已运行的压力**：世界异变已在发生（喷火狮子上新闻、体制内警戒）；常春藤已变异四天
- **切入窗口**：林野开门见客厅被藤蔓吞没的瞬间——日常与异常的最短路径
- **第 1 集入口三候选**：
  1. 时序入口：放学巷子+室友闲谈狮子传闻 → 第一帧=巷口少年背影。问题弱（只是铺垫），弃
  2. **收益入口（选定）**：开门见藤蔓客厅+「别装了，你能听懂」 → 第一帧=推开门缝，绿光里满屋藤蔓齐刷刷转向镜头。观众问题：「这些植物为什么在看他？」零门槛、一镜立人设+危机+目标
  3. 冷开（EP2 三怪火攻提前）：观众不认识钱多多、不懂任务规则，违反 STY-09 兑现依赖已建立事实，弃
- **为什么不更早/更晚**：更早=四天实验流水账；更晚=丢失「亲手杀死自己养的植物」的情感反差
- **开场可见证据**：藤蔓身上的刀疤/火烧疤/电击疤（视觉化「四天实验史」，替代记录本长念白）
- **观众现在必须知道**：林野独居、植物是他养的他试的、它有智能、它先动手
- **观众暂时不需要知道**：系统背后是什么、玩家选拔机制、世界异变全貌、窥视者身份
