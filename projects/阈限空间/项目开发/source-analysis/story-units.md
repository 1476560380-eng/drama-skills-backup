# 剧情单元

## 故事框架

**升级流 × 单元剧**（与 S1 快评判断一致）。系统等级/任务/评级构成升级主干；本章含一个完整任务单元「捉迷藏」，按任务切集天然贴合短剧结构。

## UNIT-01 常春藤反杀与系统降临

| 字段 | 内容 |
|---|---|
| 章节范围 | ch-1（P1–P9） |
| 进入状态 | 观众与林野都不知道：常春藤已是「玩家」；林野只有四天实验记录与一屋子自制武器 |
| 核心冲突 | 林野 vs 变异常春藤（三蔓绞杀+精神攻击+吸血） |
| 代价 | 林野小腿两排血洞、衣烧洞发燎焦（L53-55）；常春藤被消灭 |
| 出去状态 | 林野成为 LV1 玩家、持灵藤手镯、接到不可拒绝任务「捉迷藏」（39分钟倒计时，失败=抹除）；世界异变公开化（系统宣言）。下一单元必须继承：倒计时、武器库已清点、屋外有怪物 |

## UNIT-02 捉迷藏守家战

| 字段 | 内容 |
|---|---|
| 章节范围 | ch-1（P10–P21） |
| 进入状态 | 承接 UNIT-01：倒计时34分钟时钱多多敲门；观众已知任务规则（不离开房屋+存活），钱多多一无所知 |
| 核心冲突 | 林野+钱多多 vs 三怪（红衣女、黑毛兽、地底爪怪），规则约束=不许出门 |
| 代价 | 钱多多被逼独自下一楼捡布条（心理代价）；窗玻璃全碎、房屋损毁（后被系统复原）；一夜未眠 |
| 出去状态 | 任务SSS完成、游戏模板解锁、+15游戏币/+150经验/物品×2；钱多多获临时观测者权限（可见系统不可交互）；老槐树下窥视者未明；系统角标【第2天】 |

## 阈值自检

- 归属置信：21/21 = 1.0（两单元各推各自的核心冲突，无骑墙点）
- 覆盖率：21/21 = 100%（单章线性叙事、不足30章，属小体量例外，复核重点=是否两条剧情硬并一单元——本处两单元目标/对手/节奏均独立，无硬并）
- 重叠率：0/21 = 0（无跨单元共享情节点；P9 武器清点归属 UNIT-01 尾/UNIT-02 备战衔接，按「备战蒙太奇」归 UNIT-01 出去状态）
