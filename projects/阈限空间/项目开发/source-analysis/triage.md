# 改编价值快评

> 本快评基于抽样：读了 1 章中的 1 章（100%，原著目前仅提供第一章）。单章全量，结论直接成立，但全书走向仍属「原著未覆盖」。

## 1. 故事框架

**升级流 × 单元剧**。系统面板（LV/经验/任务/SSS评级）给出长线升级框架；本章的「试炼任务·捉迷藏」是一个有始有终的完整单元（触发→备战→三面夹击→火烧清场→结算）。单元剧结构与短剧集结构最贴合，按任务切集天然成立。

## 2. 三类判定比例（分母 1 章）

| 判定 | 占比 | 说明 |
|---|---|---|
| `screen_ready` | ~85% | 主干全是可见行动与对白：藤蔓袭击、硫酸/喷火反击、钱多多夜访、窗外红衣人、三怪攻屋、捕兽夹+铁丝+电锯+火攻、任务结算、写作业收尾 |
| `needs_carrier` | ~15% | ①实验记录本四条结论（可保留为道具特写，载体可换）；②林野对任务规则的内心推演（L123、L185-187、L279，需转成自语或钱多多追问逼出）；③系统播报长段世界观宣言（L59-69，可压缩为 UI 面板快闪+旁白） |
| `prose_only` | 0% | 无叙述性诡计、无读者-叙述者专属信息 |

## 3. 开篇替换点

冷开就落在 **ch-001 序列内（开篇即高潮）**：林野开门见客厅被藤蔓吞没 → 「别装了，你能听懂」→ 三蔓暴起绞杀。收益类型=奇观+悬念+主角「 scientific 冷血狠人」人设一镜立住，同时交代身份（高中生独居实验狂）、眼前危机（变异常春藤）与目标（活下去/搞懂系统）。**无需替换，第一章自带短剧第一集的一切要素**，这在改编里是最省事的一种。

## 4. 制作负担量级

- 同框人物：最多 2 人（林野、钱多多）+ 3 只怪物（红衣女、黑毛兽、地底爪怪）
- 空间：1 个主空间（老式独栋两层小楼：客厅/楼梯/二楼栏杆/后院铁门）+ 巷子外景。全章 90% 发生在一栋楼里，**单主场景**，制作集中
- 特效负担：中偏高——藤蔓活体运动、血气护盾光膜、硫酸碳化、大火焚烧三怪、房屋损伤复原、系统 UI 悬浮面板、怪物肢体异形（红衣女蜘蛛式爬墙）。AI 视频模型对「多怪物同框动作戏」是主要压力点
- 可读文字：系统面板、实验记录本、数学卷子，量中等
- 跨时间造型变化：无（单夜故事）

## 5. 三处最大改编风险

1. **怪物动作戏的模型上限**（ch-001 P10-P13）：三只异形怪物+火烧+爬墙+电锯，是全章最大奇观也是最大翻车点，Seedance 生成多怪物协同攻击容易肢体崩坏——需分镜上拆成单怪特写+反应镜头拼接
2. **系统播报的信息密度**（L59-69）：长段世界观宣言直接上屏会拖死 90 秒节奏，必须压缩成 UI 快闪+一句旁白，世界观后置到 EP2-3 补
3. **钱多多的喜剧-恐怖平衡**：口吃+川渝方言+碎碎念承担全章喜剧压舱，若配音/表演过火会把恐怖稀释成闹剧，过冷则失去观众情绪调节器——TTS 配音需单独调教

## 6. 分集候选量级

本章（约 7600 字，1 个完整任务单元+1 个人物入场+3 个悬念钩子）≈ **2–3 集 × 90 秒**。从 1/1 章推出。若原著按「每天一个任务」推进，10 集规格大约需 3–4 章体量。
