# 世界设定归纳

来源仅 ch-1。标不出章节的设定一律未写。

## 力量体系

| 设定 | 内容 | 来源 |
|---|---|---|
| 玩家资格 | 系统随机选拔当前世界原生居民，种族不限（植物可当玩家）；资格可通过「消灭」跨物种转移（L59-79） | ch-1 |
| 等级 | LV1、经验 0/100（L61）；经验/游戏币可因表现评级上浮至 150%（L329） | ch-1 |
| 任务 | 试炼任务为夺取玩家资格专属；任务不可拒绝；失败惩罚=剥夺资格并「抹除」（L105-117） | ch-1 |
| 奖励 | 游戏币、经验、随机超凡物品、游戏模板解锁（L331-337）；任务后环境无损复原（L339） | ch-1 |
| 临时观测者 | 近距离接触者可被玩家授予：可见系统界面、不可交互（L349-353） | ch-1 |
