# 短剧故事引擎

## 1. 已接受的戏剧承诺

- **来源**：creative-brief v1（2026-10-19）
- **焦点人物与追求**：林羽；带妹妹活着抵达安全区并在光幕选择中变强
- **昂贵阻力**：光幕难度递增 + 解析透支 + 陈漠势力觊觎 + 车队的工具化期待
- **反复回报**：死局拆解的智力爽感、序列晋升、群像选择对照
- **核心代价**：解析的身体负荷与暴露风险；算得越准越被当工具/猎物
- **终止性转变**：出题者真相揭晓，或代价积累到不可逆

## 2. 引擎回路

### 压力怎样启动

光幕在世界随机位置出题；车队为生存必须作答（物资、通行、解毒、庇护都可能是奖励）；题目难度与价值同步上涨，必死局混在其中。

### 主角惯常怎样应对

- 策略：解析当前题 → 识别死局/真奖励 → 以最小代价方案执行或拒答（部分题可拒答，部分强制）
- 为什么有效：他掌握全队唯一可靠的决策信息
- 为什么同时制造新问题：每次解析透支身体；被解析的人会发现「他在替我们决定生死」；强解析会引来「注视」

### 对抗力量怎样学习与反制

- 对抗者/约束：①光幕（出题难度随林羽胜率上涨）②陈漠（拿活人试题、反推解析者存在）③老葛（软性绑架：车队舆论）
- 目标与筹码：光幕要「变量回归均值」；陈漠要夺人；老葛要保权
- 能封住主角哪条路径：强制题（不可拒答）封「躲」；人质/群命封「独善其身」；高阶碎片信息封「全知」
- 受到压力后会怎样改变策略：陈漠从试探→收买→直接猎捕；光幕出「群体选择」绕开林羽一人决策

### 一轮冲突怎样留下下一轮压力

```text
触发：车队遇到光幕题（往往是死局伪装）
→ 主角选择：解析（付代价）→ 给出方案或亲自动手
→ 反制：题目真相比预期多一层 / 人心不配合 / 陈漠趁乱介入
→ 局部结果：当集兑现（保命/得奖励/晋升），但付出可见代价
→ 新代价/状态变化：序列↑、身体↓、信任或敌意↑
→ 下一股压力：更强的题或更近的猎人
```

### 为什么人物不能轻易退出

妹妹小雨在队里；弃用解析等于让车队死在下一道死局；「看见死局却不说话」对林羽比透支更难。

## 3. 可升级的状态

| 状态维度 | 当前起点 | 可能怎样变化 | 变化会迫使谁作什么选择 |
|---|---|---|---|
| 权力/许可 | 车队新人，无话语权 | 成为事实决策者 → 被畏惧 | 老葛夺权或让位；周凯站队 |
| 知识/误信/证据 | 只知题目表层 | 逐层解析出序列/出题者线索 | 林羽决定深入还是收手 |
| 关系/联盟/债务 | 只欠妹妹 | 与周凯结盟；欠车队人情；被陈漠标记 | 小雨要求参与选择 |
| 暴露范围 | 无人知其能力 | 车队→陈漠→（暗示）出题者 | 逃亡路线与藏匿策略 |
| 资源/时间 | 三袋面包级物资 | 奖励跃升：武器→非凡途径 | 分配即政治 |
| 物理状态 | 健康 | 鼻血→晕厥→慢性不可逆 | 解析频次与深度取舍 |
| 道德代价 | 无 | EP003 处决队友；EP006 见死不救选项 | 与许念念的答案对撞 |

## 4. 人物行动模型

### 林羽 / SD-LINYU

- 意识到的追求：活下去、护住小雨
- 被保护的价值：小雨；「不再因选错失去家人」
- 被捍卫的信念：算得准 = 不失去
- 前史成因：父母死于错误选项后果，他当时没能看清题
- 自我解释：「我不是冷血，我是不再赌」
- 惯常策略：解析→最优解→果断执行（含亲手处决）
- 可用筹码：解析、渐升的序列、信息差
- 持续盲区：把人当概率会伤害小雨与许念念式的人
- 底线与越线条件：小雨不可用于任何交换；为全队可牺牲「该死的人」
- 可能改变策略的事实：DEV-02 碎片误导致错杀/错救
- 压力下的语言与行为变化：话变少、指令化；深析后手抖、扶墙

### 陈漠 / SD-CHENMO（反派）

- 意识到的追求：在末世建立「由我出题」的秩序
- 信念：光幕是筛选，弱者的死是答案的一部分
- 筹码：序列者打手、以人试题的实验数据
- 盲区：以为解析者也只是「更好的答案」，不理解代价
- 底线：无；唯一在意自己的「正确」
- 压力下变化：由风趣收买转为公开暴力

### 老葛 / SD-LAOGE（车队队长）

- 追求：队长权位与物资分配权
- 筹码：车队资历、物资账本
- 盲区：把林羽当工具，触发 EP006 反噬

### 周凯 / SD-ZHOUKAI（前刑警）

- 追求：秩序与「少死人」
- 转变线：怀疑林羽独裁 → EP003 认可其裁决 → EP006 与其共担群体选择

### 许念念 / SD-XUNIANNIAN

- 追求：不牺牲任何人的选择
- 功能：道德对照；EP006 承受「救不过来」的现实

### 林小雨 / SD-XIAOYU

- 追求：哥哥不为自己而死
- 转变线：被保护者 → EP008 主动走进选择题

### 人物跨集进展（第一季）

| 角色 | 进入策略 | 压力测试 | 选择/回撤 | 局部结果与代价 | 离开时的可见策略 |
|---|---|---|---|---|---|
| 林羽 | 藏起解析、只保妹妹 | 原例死局迫他出手 | 出手救人→暴露 | 被车队接纳+被注视 | 有条件供解析 |
| 林羽(中段) | 拒当工具 | 处决叛徒/群体选择 | 杀伐果断执行 | 敬畏与隔阂并存 | 成为事实领袖 |
| 林羽(季终) | 靠算无遗策 | 安全区=最大选择题 | 解析强过安全区 | 代价不可逆初现 | 带队拒入，另寻路 |
| 陈漠 | 试探收割 | 林羽拆其人肉题库 | 猎捕 | 首败、损部众 | 愈发疯狂 |
| 小雨 | 被保护 | 哥哥晕厥成常态 | 要求参与 | 获得一次自己选择的权利 | 主动走进题 |

## 5. 关系压力网

### 林羽 ↔ 林小雨

- 林羽需要：她活着（唯一底线）
- 林羽害怕她看见：自己处决队友时的果断
- 林小雨需要：哥哥不只是「解题机器」
- 林小雨害怕拿走：哥哥为护她透支的命
- 当前权力位置：林羽全权代选 → 逐集滑向「她要回选择权」

### 林羽 ↔ 车队（老葛/周凯/许念念）

- 车队需要：解析保命
- 车队害怕：他的选择以他们为筹码
- 林羽筹码：唯一信息源；车队筹码：人数、物资、舆论
- 位移：怀疑 → 依赖 → 敬畏 → 分裂（EP006）→ 重建（EP008）

### 跨集记忆最小集

- **人物**：林羽序列阶级与身体损耗账；小雨知情程度；陈漠损失
- **关系**：车队对林羽态度版本；周凯站队状态
- **信息权限**：F-01…F-05 各自推进；DEV 条款披露进度（观众全知 DEV-01/03，DEV-02 误区随剧情揭）
- **活跃铺垫债务**：S-01…S-04
- **精确交接**：每集片尾的位置、持物、伤势（鼻血/绷带）、进行中的危险

## 7. 主题进入选择

- **难以兼得的价值**：算得出概率 ↔ 救不了每一个人
- **主角起初的答案**：选存活率，情感不计入
- **其他答案**：许念念「可以都不牺牲」；老葛「牺牲别人」；周凯「按规矩来」
- **代价**：EP003 林羽的答案正确但失去许念念们的亲近；EP006 群体选择让三个答案同场对撞
- **保留含混**：杀伐果断是守护还是异化，不写结论

## 8. 视觉、声音与制作方向

- **核心场域**：公路 + 废弃服务区 + 移动车队——线性逃亡天然适合竖屏纵向构图与「下一站」结构
- **改变意义的物件/声音**：光幕的青蓝冷光与嗡鸣（危险/机遇双重记忆）；林羽的鼻血（每次爽感的账单）；大巴车厢（移动的群像舞台）
- **视觉气质**：灰黄末世底色 × 光幕青蓝高亮；解析瞬间瞳孔特写 + 碎片化数据流
- **声音气质**：环境低频压迫；光幕出现=骤静+嗡鸣；解析=高频细响
- **规模边界**：怪物以特写/剪影/局部呈现（控制作成本）；大场面用光幕文字与人群反应替代
- **不采用**：长镜调度密集的写实打斗；全量展示的虫群/兽潮

## 9. 引擎终止与变形

- 人物变化：林羽承认「有些选择不该由我代选」（把选择权还给小雨/车队）→ 旧引擎松动
- 事实公开：出题者存在公开 → 光幕从规则变成对手
- 关系变化：车队学会自选 → 林羽从解药变成教师
- 终止后情绪结果：哥哥从「替你选」到「陪你选」
- 仍开放：出题者身份、序列尽头、安全区真相（第二季燃料）

## 10. 分集交接原则

- 每集兑现：至少一次解析爽点 + 一次状态实质变化
- 持续运动维度：序列/资源/暴露/身体/车队信任
- 绝不无原因重置：身体损耗、已死人物、已暴露信息
- 允许例外：无（第一季不用跳时/梦）
- 待解决：见简报第 8 节
