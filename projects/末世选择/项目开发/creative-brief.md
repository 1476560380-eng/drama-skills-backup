# 短剧创作简报

## 1. 项目意图

- **暂定名**：《末世选择》（备选：《解析者》《光幕降临》）
- **一句原始想法**：2028 年末世降临，诡异入侵、人类迁徙求生；全球随机出现光幕选择题，完成有奖励（物资→非凡途径）也藏致命陷阱；林羽觉醒「特殊解析」，可以解析一切选择，从此杀伐果断、序列晋升、群像公路求生。
- **这次要完成的工作**：系列开发 + 第一季分集规划（8 集）
- **来源材料**：创作者提供的作品简介（本会话）
- **不可更改的来源事实**：
  - 2028 年末世、诡异入侵、城市沦陷、公路迁徙 → EP001 开场世界观，观众看到的是：沦陷城市中的逃亡车队与公路
  - 光幕选择题（奖励 + 致命危险，含必死局面） → 每集核心装置，EP001 首题即用创作者原例（C-302 末世蟑螂 vs 一亿只美洲大蠊）
  - 林羽觉醒特殊解析，可解析一切选择 → EP001 觉醒并首次使用
  - 杀伐果断的主角基调 → EP003 首次处决见行动
  - 序列（非凡途径）体系 → EP002 首次获得非凡奖励，EP005 首次晋升
  - 群像 → EP002 起车队群像逐步展开
- **允许改编/探索的范围**：解析能力的具体边界与代价、车队人物、反派势力、光幕背后的真相、季终走向，均为本轮新增设计，逐条见第 5/6 节。
- **原著没有、本轮新增的内容**：
  - 妹妹林小雨 → 给林羽「不能退出」的保护义务；原著只有林羽一人，缺关系压力 → 待创作者确认
  - 车队群像（老葛、周凯、许念念）→ 承担群像承诺；原著简介无具体配角 → 待创作者确认
  - 反派陈漠及其「收割者」势力 → 提供人类对抗面，光幕本身无法成为持续人格化对手 → 待创作者确认
  - 解析的代价体系（见故事引擎 DEV 条款）→ 原著说「可以解析一切」，本轮为保悬念加边界，属对原意的约束性改编 → 待创作者确认

## 2. 创作者契约

- **希望观众反复获得的体验**：①看穿死局的智力爽感（解析揭示真相）②序列晋升的数值成长 ③杀伐果断的裁决时刻 ④群像中人心与选择的对照
- **不希望作品变成什么**：无脑碾压流水账；主角全知后没有悬念
- **主题张力**：算得出概率 ↔ 救不了每一个人（理性解析 ↔ 人命不是数字）
- **语气与尺度**：末世冷硬、强烈、杀伐果断；暴力直接但不血腥展览
- **结局承诺或禁区**：开放（光幕源头/出题者留长线）
- **内容边界**：漫剧尺度，怪物可惊悚不猎奇；无色情

## 3. 形式与制作边界

- **主要语言**：中文（zh-CN），提示词英文
- **画幅/观看场景**：9:16 竖屏短剧
- **单集与系列形式**：漫剧/AI 动画；第一季 8 集，单集约 90–120 秒（待确认）
- **可用角色与场景规模**：核心 5–6 人 + 车队背景；场景以公路、废墟、服务区、车厢为主，控制换景
- **难以承受的制作元素**：大规模人群战斗、复杂群集怪物（一亿只蟑螂等以「光幕文字 + 局部特写 + 反应」表现，不全量展示）
- **必须保留的视觉/声音特征**：光幕（青蓝色悬浮文字界面）是每集视觉锚点；解析发动时的视觉签名（瞳孔纹路/数据流 + 身体代价可见化）
- **项目节奏档案（候选）**：漫剧竖屏默认起步，未改动

## 4. 戏剧承诺（工作版）

- **焦点人物**：林羽
- **当前追求**：带妹妹活着抵达安全区，并在光幕选择中稳步变强
- **昂贵阻力**：①光幕题库本身（必死局、高耗题）②想夺取/利用解析能力的人类势力③解析的身体代价与暴露风险
- **独特矛盾**：解析越强、代价越重；他算得越准，越被车队当工具、被敌人当猎物
- **反复回报**：每集至少一次「死局拆解」的智力爽感 + 状态实质变化（序列/资源/关系）
- **终止性转变**：林羽解析出光幕的「出题机制」真相，或解析代价积累到不可逆

**一句工作陈述**：一个每次动用解析都要付出身体代价的末世哥哥，在公路迁徙中靠拆解死局带着车队活下去，却被光幕和人类同时盯上——他算得出每个选择的死亡率，却算不出人心的选择。

## 5. 方向候选与选择

### 候选：解析有代价（选定）

- 主角惯常策略：关键时刻解析，用最小代价换取安全高收益
- 主要对抗机制：光幕难度递增 + 解析透支 + 人类势力觊觎
- 退出成本：不用解析 = 车队死在必死局；妹妹依赖他的判断
- 反复回报：拆题爽感、序列晋升、群像选择对照
- 核心代价：身体负荷（鼻血→晕厥→不可逆损伤）+ 高阶题只给碎片概率 + 深度解析会被「出题者」感知
- 引擎终止条件：出题者真相揭晓 / 代价不可逆
- 主要制作负担：每集需要一道可视化的选择题界面 + 一次解析视效
- 擅长提供：悬念 + 爽感并存，长线可升级
- 会牺牲：纯碾压式爽感（每次爽都要付账）

### 创作者选择

- **选定/组合**：解析有代价（本次会话确认）
- **选择理由**：解析全知会取消阻力；代价体系保住悬念并强化「每个选择都有重量」的主题
- **明确拒绝的方向**：全知掌局流（阻力全靠人类反派，光幕沦为道具）；解析即诅咒（爽感激进口味不符）
- **仍待确认的分支**：季终是否抵达安全区；妹妹设定是否保留

## 6. 核心人物与关系压力

### 林羽（主角，解析者）

- 当前目标：带林小雨抵达传闻中的安全区
- 保护对象：妹妹林小雨
- 被捍卫的信念：只要算得够准，就不会再失去家人
- 前史成因：末世首日因「选错」失去父母（父母替他挡了错误选项的后果）
- 惯常策略与优势：解析 + 冷静权衡，杀伐果断
- 策略盲区与代价：把人命当概率时会伤到身边人；身体透支
- 可用筹码：解析能力、逐步晋升的序列
- 底线与可能越线条件：底线是小雨；若解析显示「牺牲一人救全队」，他会动手并承受道德重量
- 可能改变其策略的事实：解析出现「误述」（高阶题碎片信息误导）

### 林小雨（妹妹，新增待确认）

- 当前目标：跟着哥哥活下去，但不愿看他为车队透支自己
- 被捍卫的信念：哥哥不该是所有人的解药
- 功能：林羽的退出成本 + 道德镜子

### 周凯（前刑警，车队护卫，新增待确认）

- 目标：维持车队秩序；对林羽从怀疑到结盟
- 筹码：武力 + 民意；盲区：程序正义在末世失效

### 老葛（车队队长，新增待确认）

- 目标：保住队长地位，想把林羽变成「车队的工具」
- 关系压力：与林羽的利用/反利用；EP006 夺权失败出局

### 许念念（大学生，新增待确认）

- 道德对照组：相信「选择可以不牺牲任何人」；她的每一次失落与坚持都测试林羽的答案

### 陈漠（反派，「收割者」首领，新增待确认）

- 目标：收割序列者与「能看穿题目的人」，建立选择霸权
- 筹码：囤积的序列者打手 + 对光幕规则的疯狂实验（拿人命试题）

### 核心关系：林羽 ↔ 林小雨

- 林羽需要小雨作为底线；小雨害怕哥哥把自己当成「必须活下去的选项」
- 不平衡：林羽替她做所有选择
- 可能变化：小雨要求参与选择（EP006–008 成长线）

### 核心关系：林羽 ↔ 老葛/车队

- 车队需要他的解析保命；林羽害怕被当成工具
- 可能变化：从被利用 → 被敬畏 → 被畏惧（杀伐果断的阴暗面）

## 7. 叙事切入窗口与前史储备

- **故事切入前已经运行的压力**：末世已爆发数周，城市沦陷进行中，光幕已出现多轮，人类已总结出「选择题有奖励也有死局」的常识
- **叙事切入窗口**：城市弃守当日，林羽被卷入一道公开光幕题（创作者原例），觉醒解析
- **第 1 集入口候选**：
  1. 冷开（选定）：第一帧——废墟超市上空悬浮青蓝光幕，题面正是「A：战胜C-302型末世蟑螂 / B：与一亿只美洲大蠊在封闭房间中待1小时」，跪地的幸存者无人敢选，镜头推向人群后蜷着妹妹的林羽，瞳孔亮起解析纹路，鼻血滴落——问题：他看到了什么？
  2. 时序入口：末世首日父母之死 → 情感足但爽感迟到，弃
  3. 收益入口：车队半路遇题靠林羽化解 → 缺觉醒时刻，弃
- **为什么不更早/更晚开始**：更早是末日准备流水账；更晚丢掉「觉醒 + 原例名场面」
- **开场可见证据**：林羽父母缺席 + 他对光幕的恨意、妹妹的依赖，反推前史
- **观众现在必须知道**：光幕规则（选了必须做、奖励真实、有死局）、林羽解析有代价、小雨是底线
- **观众暂时不需要知道**：父母之死细节、光幕来源、出题者存在（EP008 才露爪）
