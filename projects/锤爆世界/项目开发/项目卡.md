### 剧本.md

- 一级标题 `# EPxxx 集名`；场景标题 `## EPxxx-SCxxx 内/外 · 地点 · 时间/天气`。
- 对白一律 `角色（可执行提示）：台词`。**冒号前必须带括号提示**——写成裸的「高铁锤：台词」会被索引判成 `ambiguous_dialogue_or_action`，整份索引进 review_required。
- 生产标签只用 `[VO]` `[OS]` `[SFX]` `[画面文字]` `[连续性]` `[转场]`。
- 每场首行写一条 HTML 注释，标出本场拍点数量与该场实际需要的秒数。
- 动作写现在时、可见可拍；不用解释替代行动，不把演过的机制再复述一遍。

### 视觉设定.md

- 条目必须是二级标题 `## 类别 · 名称`，类别只能是 人物 / 造型 / 地点 / 道具。**禁止** `## 人物` 分区 + `### 名字`（跨文档检查器只认前者，写成后者会让分镜所有视觉依据集体失效）。
- 每个人物与造型条目必须有一行 `- 画面代称：X`（不加粗），英文拼写全集唯一、大小写统一；正文从不点名就写 `画面代称：无`。
- 先写「识别锚点」（什么不变使它还是同一个资产），再写「本集状态」（起始 → 变化 → 结束）。
- 连续性锁只锁**跨镜不变的可见事实**，锁面用提示词语言写成最小名词短语，下游原样抄进关键帧正文。
- 世界观层面的可见规则（如本剧的黑墨状血）写成独立道具条目，不当成描写细节随手带过。

- **像素预算（2026-10-25 修订，替代旧的「8 个视觉单元上限」）**：不作单元数上限，改按尺寸算——每张脸 ≥300px 宽、每格局部 ≥200px、色板每块 ≥80px，整图按下方分辨率条出 4K。算下来不够就放大画布、减格数或拆 A/B 卡。四视图里的人脸必须能被放大核验，1280×720 下四视图脸只有约 35px，等于无法验收。
- **四视图一致性（人物卡必写）**：①四个视图是**同一个已锁定模型仅旋转观察角度**，不是四次重画；②左右侧面**严格朝向相反方向**，背面**严格背对镜头**，禁止两个侧面同向、禁止缺背面；③零件级一致清单逐项点名：领口形状、袖子长度、裤腰高度、裤线、口袋位置、配饰与腕表位置、发型与秃发/灰发分布、手部疤痕位置；④四视图双手空置、不持道具、不戴手套，确保双手与服装结构清楚可见。
- **群像卡（T-GRP，2026-10-25 新增）**：一伙人共用一个资产卡——左侧主视觉群像（按身高与体型排序、留间距不遮脸）、中间 N 行四列（一人一行，四个朝向）、右侧 N 格正面头像（标 A/B/C…）、底部集体动态＋线稿＋身高标尺、色板按服装配色。必写三句防错：①「这是同一组 N 名成员的多角度展示，**不代表新增 N×4 名角色**」；②「N 人的脸型、年龄、身高、体型、发型、服装配色必须明确区分，禁止复制脸与统一模板体型」；③「同一成员在不同区域的服装、鞋子、发型、配件位置完全一致，禁止成员串脸与交换服装」。身高：设定过的写厘米并配标尺，未设定的只写相对比例，不编数值。
- **比例尺与线稿（2026-10-25 依参考定）**：比例尺**不用数字刻度**，改用**部位锚线**——头顶／肩部／胸部／腰部／膝盖／脚底 六条横向虚线＋右侧部位名，天然避开「编造未设定身高」；线稿区画**四个视图**（正面／侧面／背面／反向侧面），不只画正面。
- **表情区裁剪下限（2026-10-25 实测教训）**：戴帽/戴头盔的角色可裁到「帽檐＋眉眼横条」省空间，但**必须保留到嘴部或下巴**。参考案例裁到只剩眉眼后，「紧张」与「认真汇报」两格几乎无法区分，表情区失去辨别功能——宁可少一格表情，不要三格分不出。
- **身份标识防护**：赛博朋克/现实题材资产卡禁止项必含「真实机构标识」——警徽、军衔、国徽、真实企业 logo、证件号码。虚构组织的徽记用几何图案，不模仿现役制式。
- **出图分辨率**：资产卡一律 **4K（3840×2160）** 出图。1280×720 下四视图人脸只有约 35px，等于无法验收；参考样本能立住细节靠的就是 4K。
- **资产级画面文字**：属于资产本身的文字（胸标「保安」、悬赏令标题、门牌）按 `exact_readable` 逐字写进提示词并允许清晰可读；但同一张卡里不得同时出现「禁止一切文字」的负向词。
- **三类卡分工**：人物卡/道具卡＝棚拍资产逻辑（干净白底、均匀柔光）；场景卡＝实景光逻辑（有可解释的实用光源）。对齐的是质感语言，**不对齐亮度分布**——场景卡和人物卡一样干净反而是错的。
- **场景卡版面禁忌**：纯四等分四视角，**不加底部细节条**（2026-10-25 实测：上四下二会退化成五个等大格，明显差于纯四等分）；会被特写的物件（灯罩裂纹、滴水、消防栓箱）另出小尺寸物件卡；场景板不写名称/用途文字条，文字进「图外标注」。
- **参考用图纪律**：场景四宫格只给人看；挂进关键帧做参考用**单视角干净图**（无格线、无标签、无文字），一镜一图。
- **画面内的文字政策（2026-10-25 依参考修订）**：允许**大字号短标签**——分区名（四视图／表情参考／头部细节区／角色主色板／动态参考／细节展示／线稿参考／人体比例尺参考）、视图名（正面／左侧面／右侧面／背面）、成员编号（A/B/C/D）、表情名（四字以内）、色板单行 HEX（每块一个，如 `#556575`）。禁止：中文色名小字、多行长句说明、正文字号说明句、假字与乱码。理由：实测「大字号、少字数、规整对齐」能出，密集小字必糊。
- 双语渲染增强尾：**全项目只有一个口径（2026-10-26 裁决）**——`3D Chinese animation style，semi-realistic，high-end CG，studio lighting，soft film grain`。资产卡、关键帧、视频提示词逐字相同，不再二选一；实拍口径 `photorealistic cinematic still` 已废，只留在 `审查/样板-旧EP001网文版/` 里作历史对照。
- 负向词必带：防合图、锚点丢失、画面内出现可读文字与假字、外景背景/天空/地面投影（白底卡）、重复的正面视图、两张相同的脸；人物卡另加人种与面部毛发守卫（角色设定本身要求外国人/胡须时不加）。

### 分镜.md

- 头部必写 `- 强制项：轴线锁、亮度口径`（默认全强制，fail-closed）。要豁免必须创作者亲口说，写 `- 规格：legacy`。
- 每个 `SEG-` 段头必写：情绪基调／色调／场景设计 + **轴线账**（`轴线：甲 ↔ 乙｜机位：…｜甲 画面左 / 乙 画面右`）+ 镜头基准（本段默认焦段/景深）+ 光线锚点（night/dawn/lamplit…）+ 曝光基准。写不出轴线账的场次不得拆分镜。
- **镜头语言逐镜选、逐镜写理由**，严禁按景别套模板（「镜头是根据剧情和表现力来的，不是套用相同的」）。焦段只用 24/35/50/85 四档，f 值只用三条语义轴（深焦 f/5.6+ ／叙事 f/2.8 ／浅焦 f/2.0-）。同段可重复同一焦段——重复本身是设计，但要能说出为什么。
- **静帧化**：动作进行时一律改成「动作后定格」；必须保留进行时时，句尾加具体结果禁句（`no motion blur on face`、`tears stay in her eyes, never fall`），不写「静止」「不模糊」这类抽象禁令。
- **亮度四层**：①调色词拆「色相 + 明度」，禁止单用 `moody`/`muted`/`dark` 代表亮度 ②每镜写 `key:` 与 `fill:` 两个光源，夜景/逆光必须有补光，人脸对背景 ≤1:4 ③负面词 `underexposed, crushed blacks, murky shadows` ④曝光句 `Exposure balanced for …`。
- **画风句拆两截**：质感锁 `3D Chinese animation style, semi-realistic, high-end CG, studio lighting, soft film grain` 全片统一；调色词按 SEG 段头逐段翻译，同段一致、段间按翻转设计切换。段内确有变化时在那一镜正文写「刻意破格」，并保留段头调色词。
- 每镜必写字段：职责、来源（剧本真实场景 ID 开头）、时长（0.5s 精度）、景别/机位、**运镜（带理由）**、镜头技术捕捉（起幅→意图→落幅交接）、起点 → 唯一动作 → 终点、声音、配音指令（角色｜音色｜状态｜语速）、视觉依据、图片提示词项、输入参考图、**ShotDeck 参考**（逐词中英对照 `英文·中文 + 英文·中文`，6-8 组）、时间码。
- 有人物出场的镜必须写画面位置句（`on screen-left` / `on screen-right` / `facing screen-…`）；走位穿场镜加 `not part of the dialogue axis`；全景重设轴线写 `axis resets`。禁写变体（`on the left side`、`at frame left`、中文「画面左侧三分之一」）不被接受。
- 对白只写一遍：`声音` 字段只写索引（`[OS] 画外对白×2（约3s，内容见配音指令）`），逐字全文只出现在 `配音指令`。
- 生成包分组：目标模型已声明且有单镜最短时长下限时才做，沿 SEG 边界切包、每包落在模型原生窗口内，头部写「生成包总表」、每镜字段区首行写 `生成包`。
