# 《偷听》技能包 v1.0 · 清单与用法

> 2026-10-29 打包。本包自包含：`skills/` 文件夹里是 13 个技能的完整拷贝（含参考模板和脚本），本文件是每个技能的"干什么／什么时候用／对 AI 说什么／产出什么"。
> 技能的完整版装在 Hermes 的 duanju profile 里（`~/.hermes/profiles/duanju/skills/`），日常对话自动触发，**不需要手动调用**；这份打包用于交接、备份、换机器时恢复。

## 〇、一张图看懂：一集戏的技能接力

```
$short-drama（总入口，管项目）
   │
   ├─ 剧本层   $short-drama-write        ← 你给原文，它规范化（不改故事）
   ├─ 资产层   $short-drama-assets       ← 拆人物/场景/道具 → 视觉设定
   │           $short-drama-references   ← 你发的参考图，登记/分类/定锚
   │           $short-drama-image-prompts← 写设定卡出图提示词
   ├─ 镜头层   $short-drama-storyboard   ← 写分镜（45镜那种）
   │           $short-drama-video-prompts← 写多镜容器/视频提示词
   ├─ 生产层   $short-drama-produce      ← 接了 API 才能跑图/跑视频（未接）
   │           $short-drama-edit         ← 成片剪辑、字幕、响度
   └─ 质检层   $short-drama-review       ← 审任何一份产出，只提问题不动手
前置（有原著小说才用）：
   $short-drama-novel-analyze → $short-drama-develop
总控（本项目新写）：
   $duanju-ep-pipeline ← 九阶段流水线，管上面这些技能的调用顺序
```

## 一、逐个技能说明

### 1. short-drama —— 项目总入口

| 项 | 说明 |
|---|---|
| 干什么 | 初始化/继续短剧或漫剧项目：建项目文件夹、五文档结构、看进度、打开创作台 |
| 怎么触发 | 说"建新项目《XX》""继续《偷听》""现在进度到哪了""下一步做什么" |
| 对 AI 说 | "我要建新的项目卡叫偷听" / "《偷听》现在做到哪一步了" |
| 产出 | 项目文件夹、short-drama.json、项目卡.md |
| 《偷听》实例 | EP001 建档就是它干的，项目卡每次有进展自动刷新 |

### 2. short-drama-novel-analyze —— 拆原著（待用）

| 项 | 说明 |
|---|---|
| 干什么 | 把长篇小说/网文拆成章节索引、改编价值快评、剧情单元，判断"这本书值不值得改" |
| 怎么触发 | 说"导入这本小说""拆这本书""这本书能不能改短剧" |
| 对 AI 说 | "分析这本小说，看适合改编吗" |
| 产出 | 原著分析文档 → 交给 short-drama-develop 立契约 |
| 《偷听》实例 | 还没用（目前是你直接给剧本，不走小说改编线） |

### 3. short-drama-develop —— 故事开发（待用）

| 项 | 说明 |
|---|---|
| 干什么 | 把想法/梗概/多集剧本发展成故事引擎、分集地图、创作简报、导演阐述 |
| 怎么触发 | 说"开发短剧""做故事设定""写分集规划" |
| 对 AI 说 | "从《偷听》的一句话设定铺分集地图" |
| 产出 | 改编方案、分集地图 |
| 《偷听》实例 | 还没用；集数还是占位 40，等分集地图出来校准 |

### 4. short-drama-write —— 剧本编写与规范化（已用）

| 项 | 说明 |
|---|---|
| 干什么 | 写新剧本，或把你给的现成剧本**保留原文一字不改**地做格式规范化（场景头、台词格式、标签） |
| 怎么触发 | 说"写/改一集剧本""把这集规范化"，或直接把剧本原文发过来 |
| 对 AI 说 | "这是第一集内容"（附原文）——它只加 SC 场景头和拆台词格式，不改故事 |
| 产出 | 剧集/EPxxx/剧本.md ＋ 输入/original-epxxx.md（原文存档） |
| 《偷听》实例 | EP001 剧本：4 场 29 句台词，净字数 1750 与原文逐字一致 |

### 5. short-drama-assets —— 视觉设定（已用）

| 项 | 说明 |
|---|---|
| 干什么 | 从剧本拆出人物/造型、地点/视图、道具/状态，写成视觉设定；判断复用还是新变体 |
| 怎么触发 | 说"拆角色/场景/道具""做资产设定" |
| 对 AI 说 | "把这集拆成视觉设定" |
| 产出 | 剧集/EPxxx/视觉设定.md（每条含识别锚点/状态变化/英文代称/跨镜不变锁/Q版切点/下集交接） |
| 《偷听》实例 | EP001 视觉设定 12 条（2 人物 4 地点 6 道具） |

### 6. short-drama-references —— 参考图管理（已用）

| 项 | 说明 |
|---|---|
| 干什么 | 管参考图全生命周期：分类登记、解析、选锚图、绑定校验；规矩是"画风图只管画风、人物图只管长相、环境图只管空间，互不越界" |
| 怎么触发 | 发参考图给 AI，说"这是参考图" |
| 对 AI 说 | "这些是参考图"（AI 会先给初判分类表，你确认后登记） |
| 产出 | 输入/参考图/登记表.md ＋ 解析.md |
| 《偷听》实例 | 5 张参考图初判 + 3 张锚图登记（C01 洛洛/C04 小药/L01 药庐峰），45 镜挂图对齐 |

### 7. short-drama-image-prompts —— 图片提示词（已用）

| 项 | 说明 |
|---|---|
| 干什么 | 写可直接复制的设定卡出图提示词：人物卡/场景卡/道具卡/状态变体 |
| 怎么触发 | 说"写角色设定图提示词""出三视图""做场景板" |
| 对 AI 说 | "按锤爆卡式出这集的图片提示词" |
| 产出 | 剧集/EPxxx/图片提示词.md（编号 IMG-EPxxx-XX 的卡片） |
| 细则真源 | 它的参考文件 asset-card-template-zh.md v3（《偷听》已抄成 `项目开发/图片提示词卡规范.md`） |
| 《偷听》实例 | EP001 出了 14 张卡；先出 3 张定调卡不全量 |

### 8. short-drama-storyboard —— 分镜（已用，用户定制升级版）

| 项 | 说明 |
|---|---|
| 干什么 | 把剧本＋视觉设定写成逐镜分镜：戏剧职责、运镜＋理由、起幅落幅、动作链、配音指令、冻结关键帧、ShotDeck 参考行 |
| 怎么触发 | 说"拆分镜""设计镜头""做镜头表" |
| 对 AI 说 | "分镜头给我"（可加要求，如"开场第一镜就是人""镜头别太长"） |
| 产出 | 剧集/EPxxx/分镜.md（45 镜 / SEG 分段 / 生成包切分） |
| 铁律 | 不改故事情节；动作链用剧本原话，不加戏不减戏；镜头按剧情表现力选，不套模板 |
| 《偷听》实例 | EP001 分镜 45 镜 8 段 158.5s，切 15 个生成包 |

### 9. short-drama-video-prompts —— 视频/多镜容器提示词（已用）

| 项 | 说明 |
|---|---|
| 干什么 | 把分镜＋关键帧写成给视频模型（Seedance 等）的可复制提示词，含多镜容器（一包多镜硬切）、切点时间锚、位置承接；也可写配乐意图 |
| 怎么触发 | 说"多镜分镜给我提示词""把这包写成容器" |
| 对 AI 说 | "多镜容器，按 Seedance 4–15 秒切包" |
| 产出 | 剧集/EPxxx/多镜容器-包XX.md |
| 规矩 | 锤爆七项规则：风格块＝首镜质感锁＋三禁止、镜头参数用源分镜原句、时间锚、位置承接中文句、容器禁元话语、画内人物双轨 |
| 《偷听》实例 | 包01 试点（7 镜 13.5s，切点 2.5/4.0/5.5/7.0/9.5/11.5） |

### 10. short-drama-produce —— 媒体生产（未接通道）

| 项 | 说明 |
|---|---|
| 干什么 | 你明确确认后，执行跑图/跑视频/配音/配乐，并把结果和运行记录落回项目 |
| 怎么触发 | 说"生成这张图""开始跑视频" |
| 现状 | **本机没配图像/视频 API key，通道未接**——目前图和视频都是你自己出，AI 负责写提示词和验收 |
| 接通条件 | 给任一供应商 key（fal / GPT Image / Seedance）后此技能才真正干活 |

### 11. short-drama-edit —— 剪辑（待用）

| 项 | 说明 |
|---|---|
| 干什么 | 把已生成的镜头剪成成片：入出点、镜序、字幕、响度统一、节奏调整、导出规格 |
| 怎么触发 | 说"把这集剪出来""加字幕""统一响度" |
| 产出 | 剪辑记录＋成片规格说明 |
| 《偷听》实例 | 等 15 包视频回来后用 |

### 12. short-drama-review —— 审查（随时可用）

| 项 | 说明 |
|---|---|
| 干什么 | 审任何一份产出：剧本/视觉设定/提示词/分镜/媒体，只写问题清单和修订要求，**不代替你改文件** |
| 怎么触发 | 说"审稿""检查这集分镜有没有连续性问题" |
| 对 AI 说 | "审一下 EP001 的分镜" |
| 产出 | 审查报告（问题＋严重度＋改法建议） |

### 13. duanju-ep-pipeline —— 九阶段流水线总控（新写）

| 项 | 说明 |
|---|---|
| 干什么 | 《偷听》跑通后新写的总控技能：管上面 12 个技能的**调用顺序**和坑位规避（九阶段：建档→剧本→视觉设定→图片提示词→锚图登记→分镜→生成包→多镜容器→验证闭环→规则沉淀） |
| 怎么触发 | 做任何一集时自动套用；说"下一集开工"也会按它走 |
| 真源 | `~/duanju/偷听/项目开发/工作流程.md`（技能卡只记骨架和坑） |
| 已沉淀的坑 | 脚本丢换行、人物镜必挂场景图、锚图登记后全量刷旧描述、删文件先问、表单未送达不自作主张 |

## 二、恢复方法（换机器/给别人）

1. 把 `skills/` 下的 13 个文件夹拷进 Hermes 的技能目录（如 `~/.hermes/profiles/<profile名>/skills/`）
2. 项目本体在 `~/duanju/偷听/`，整个文件夹拷走即完整项目
3. 规则文件（工作流程/卡规范/文件规则）都在项目的 `项目开发/` 里，和技能包互为备份
