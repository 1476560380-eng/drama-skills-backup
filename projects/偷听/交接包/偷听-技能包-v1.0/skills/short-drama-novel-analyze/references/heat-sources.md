# 题材热度数据源清单

S1 改编价值快评要写「题材赛道对照」时，先按本清单取数。**原则：热度是证据，不是印象。**
任何热度数字必须有可核对来源；没有就写「未提供热度数据」，不得编造榜单、播放量、分账或站内排名。

## 一、可直接抓取（免费、免登录，2026-10 实测）

跑脚本一次拿全：

```bash
python3 {技能目录}/scripts/heat_probe.py --out 项目开发/heat-snapshot.json
```

输出的 `genre_scores` 是赛道命中数，`sources_status` 记录每个源是否成功——**引用时要连同
`fetched_at` 一起写，否则这条证据无法复现**。

| 源 | 提供什么 | 接口 | 实测状态 |
|---|---|---|---|
| 百度热搜 | 实时新闻话题，看大众注意力方向 | `top.baidu.com/api/board?platform=wise&tab=realtime` | ✅ 51 条 |
| 今日头条热榜 | 资讯热榜，覆盖面比微博宽 | `toutiao.com/hot-event/hot-board/?origin=toutiao_pc` | ✅ 50 条 |
| B站热搜 | 年轻向内容风向，漫剧/动漫赛道参考 | `api.bilibili.com/x/web-interface/search/square?limit=50` | ✅ 50 条 |
| 豆瓣热门剧集 | 在播剧列表（含评分、更新集数），短剧常在此露头 | `movie.douban.com/j/search_subjects?type=tv&tag=热门` | ✅ 30 条 |
| 番茄小说榜单 | **热门网文书名+作者+简介，小说改编侧最准的信号** | `fanqienovel.com/api/rank/list?category_id=0&rank_type=1` | ✅ 7 本/次（接口限流） |

判读方法：
- 番茄榜单里某个赛道（赘婿/战神/豪门）反复出现 → 该网文赛道在供给端仍热
- 豆瓣在播剧里出现同赛道 → 该赛道在需求端已验证
- 两者同时命中才算「当下热门」；只有新闻热榜命中属于「社会话题」，不等于短剧赛道热

## 二、需要创作者提供（登录/付费/App 内，脚本抓不到）

这些是真正的**平台级数据**，写「题材赛道对照」时价值最高，但取数必须由创作者完成，
拿到后如实引用，并写明来源与日期：

| 平台 | 能看什么 | 为什么抓不到 |
|---|---|---|
| 红果短剧（抖音系） | 短剧榜单、热度值、分账 | 仅 App/小程序内可见，网页端反爬 |
| 抖音短剧榜 / 星图 | 短剧投放与达人热度 | 接口需签名，页面 403 |
| 云合数据 | 短剧/长剧正片有效播放、市占率 | 官网可访问，榜单需会员账号 |
| DataEye 短剧观察 | 短剧热力榜、投放素材、消耗 | 官网可访问，榜单需登录 |
| 艺恩 Endata | 剧集热度、受众画像 | 需机构账号 |
| 骨朵数据 | 网络剧/短剧播放量榜 | 站点不稳定，需登录 |
| 猫眼/灯塔专业版 | 分账票房、热度 | 接口 403，需 App |

创作者给截图或复制数字时：照录进 `triage.md` 的赛道对照行，标注「来源：<平台> · <日期>」。

## 三、已知不可用（别浪费时间重试）

| 源 | 状态 | 说明 |
|---|---|---|
| 微博热搜 | 403 Forbidden | 接口需 Cookie，改用头条热榜替代 |
| 知乎热榜 | 需认证（code 101） | 未登录拿不到 |
| 抖音 web 热榜 | 空响应 | 需 a_bogus 签名 |
| 猫眼 piaofang 接口 | 403 | 改用豆瓣在播剧 |
| 七猫榜单 | 404 | 接口路径已变 |

## 四、写进 triage.md 的格式

```markdown
- 题材赛道：<原著赛道>｜热门序列：<是/否/未提供热度数据>
  - 依据：<番茄榜单 x 本同赛道｜豆瓣在播剧 y 部｜创作者提供 <平台> <日期> 截图>
  - 抓取时间：<heat_probe.py 输出的 fetched_at>
```

只写参照结论，**不参与改编密度判据**。文本能不能改成好剧，仍由三类判定比例与制作负担决定。
