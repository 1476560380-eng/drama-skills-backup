# CHANGELOG · short-drama-references

三段式记录：改了哪些 / 优化了哪些 / 兼容性验证。

## 1.1.0 — 2026-10-25（MINOR：照片参考准入硬规则）

**依据**：《锤爆世界》EP001 两次实测——挂牌照参考出人脸/服装/外景污染；裁成无人材质块后恢复可控。以及五份资产卡案例的版式结论。

### 改了哪些

- `SKILL.md` ④ 绑定与验证一节新增两条硬规则：
  1. **实景剧照不能直接挂进生成**：负面词擦不掉参考图里已有的像素，挂一张电影剧照会把剧中人物、服装、背包和外景天空整块搬进设定卡。含人物或叙事景物的照片参考必须先裁成「无人、无叙事景物」的材质块（只保留材质、光比、颗粒），存成新文件并在登记表备注「裁切材质块（裁自 XX）」，才允许进提示词。
  2. **人物卡与道具卡不挂照片参考**：画风改由文字质感锁 + HEX 色板承担；地点卡只挂材质块。
  3. **裁块要逐张验**：每块裁完确认无人脸、无人物肢体、无叙事物件（车、尸体、文字），常见失败是边缘带进半个肩膀或一只靴子。
- 新建 `VERSION` 与 `CHANGELOG.md`。

### 优化了哪些

- 参考图登记从「分类对不对」扩展到「这张图能不能进生成」，堵住此前"分类正确但仍污染画面"的漏洞。
- 材质块与原始剧照在同一张登记表内分层：原图只做同族比对，进提示词的一律是裁块。

### 兼容性验证

- `scripts/ref_check.py` 对《锤爆世界》全量核对：退出码 0，8 张登记、1 类锚、7 处 REF 槽位全部通过。
- 未改动登记表字段、用途封闭词表与脚本判据；既有项目只需把照片参考替成裁块，不需要重新分类。
