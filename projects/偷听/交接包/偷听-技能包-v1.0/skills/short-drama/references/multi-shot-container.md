# 多镜容器生成器（把分镜切成可投喂的硬切包）

目标：把 `剧集/<EP>/分镜.md` 变成「一个包 = 一段可直接复制的视频提示词」，每个包内部是若干硬切镜，
总时长落在目标模型的原生窗口内。一个成熟项目里的 `项目开发/gen_containers.py` 就是这类脚本，
新项目复制适配即可，**不要每次手写容器**；也不要手改产物——改生成器再重跑。

## 一、切包规则（先定，再写脚本）

| 规则 | 值 | 为什么 |
|---|---|---|
| 单包上下限 | 目标模型原生窗口（Seedance 2.0 为 4–15s） | 超上限会被模型截断，低于下限浪费一次生成 |
| 不跨 SEG | 沿段落边界切 | SEG 是情绪与色调的切换点，天然剪辑呼吸点；跨段会让包内出现两套调色 |
| 超窗 SEG 处理 | 在镜边界找动作闭合点二分 | 切在动作中间会让上一包尾帧和下一包首帧接不上 |
| 长对白镜 | > 4.5s 的镜尽量独占一包或放在包尾 | 同轨生成时台词容易被下一镜切点吞字 |
| 尾包 | 不低于下限 | 宁可并进上一包 |

切完在分镜头部写「生成包总表」：`| 包 | 成员镜 | 时长 | 包内内容 |`，单包时长要等于成员镜时长之和。

## 二、源分镜必须提供的五个字段（生成器全靠它们解析）

1. 镜头标题带时间码：`## SHOT-<EP>-001 · 中文名（0.0–4.0s）`。
2. 每镜字段区首行 `- **生成包**：包N（同包 SHOT-001~004）`——缺这行容器会丢镜。
3. 每镜字段区有 `- **视觉依据**`，里面 `人物/地点/道具「名称」` 与《视觉设定.md》条目名逐字一致——
   器从这行抽「本包出场人物/场景/道具」与 @资产名。
4. 每镜冻结关键帧里有一行 **`Shot on <焦段>, <f值>, <景深/机位>`**——器把它当「镜头参数」抄进容器。
   没有这行器会输出「（源分镜缺 Shot on 句）」，容器就缺了焦段与景深控制。
5. 冻结关键帧第一行是画风句（`Horizontal 16:9, …`），器把它当包级「本节风格提示词」，
   并在尾部追加禁句。所以每镜画风句必须逐字一致，不能手改其中一镜。

## 三、适配到新项目的改动点

复制生成器后按顺序改，不要重写：

1. **去依赖**：原生成器可能 `import voice_cast`（音色铸造表）。新项目没有这张表就直接删掉该模块引用，
   把「配音指令」原样透传（分镜里的 `角色｜音色｜状态｜语速｜台词` 已经能直接给 TTS）。
2. **改正则**：①画风行可能写成「画风统一句（每条关键帧共用）」也可能带「质感锁」字样，用二选一正则；
   ②SEG 段头格式、镜头标题破折号（`–` 与 `-`）两种都要兼容；③生成包表的列名可能不同，只认列位不认列名。
3. **改路径**：`ROOT = 项目根`，读 `剧集/<EP>/分镜.md` + `视觉设定.md`，输出 `剧集/<EP>/多镜容器提示词.md`。
4. **跑干跑**：不加 `--write` 先看前 3000 字，确认包数/镜数/总时长与分镜头部对得上再落盘。

## 四、容器正文的固定结构（每包）

- 包级表：硬切镜数与逐镜时长、场景、出场人物（仅挂芯片，画内以逐镜为准）、道具、全集绝对时间、跨节接镜。
- `> 本段色彩意图：<SEG 段头色调>`
- **本节风格提示词**（代码块，可直接复制）：画风句 + 禁止项 `禁止出现字幕，禁止出现背景音乐，禁止出现水印`。
- 逐镜：`本镜画内人物`（@资产名）／`首帧锁定`（关键帧正文）／`镜头参数`（Shot on 句）／`运镜`／
  `画面`（起点→动作→终点）／`位置承接`（中文左右句，从英文首帧推）／`音效`／`台词`。

## 五、坑

- **元话语不进容器**：分镜里的「理由：…」「本版新增」「呼应第 N 集」这类写给读者的话，模型会当成指令，
  入库前剥掉；剥离要正则化并在干跑时打印警告，不要人工逐条删。
- **画内人物靠两道保险**：先取「视觉依据」登记的人物，再从英文首帧里点名的名字补齐；
  补出来的要打 ⚠️「源头漏登记」提醒回头补视觉设定，而不是静默接受。
- **位置承接从英文首帧推**，不要从中文分镜描述推——中文里的「画面左侧」不能直接当位置句。
- **一包一镜也要写**：单镜成包同样有包级表与风格块，下游并联处理更省事。
