## 1. 药庐峰定调图 · `ref-l01-yaolufeng.png`

| 项 | 结论 |
|---|---|
| 分类复核 | **判定为 环境 类，次类 画风**。理由：画面信息主体是空间地理（悬空峰体、建筑、药田、药炉、云榻的相对位置与朝向），同时它承担全片暖金 CG 质感的定调来源，故声明次类画风；一张图两个槽位，用途分开写。 |
| 色板采样（近似） | `#D9B25E` 茅草黄 · `#8A5A33` 木构褐 · `#5E8F6E` 药田绿 · `#C98A5A` 紫铜反光 · `#F0E6D2` 云海米白（以人眼裁决为准） |
| 光位与硬度 | 高位侧逆日光，从左上方斜下；暖白偏金，中硬，云海大面积反弹作补光，光比约 1:2；云层边缘有强逆光轮廓。 |
| 质感归类 | **CG 渲染**（半写实 3D，非实拍、非笔触）：茅草纤维清楚、木构纹理可见、石阶有凿痕、紫铜有氧化暗部与浮雕高光。 |
| 冲突点（与现有设定） | ① **峰体有瀑布**——设定只写了"悬空山峰 + 云海"，未写瀑布；② **有石阶、木栏杆、盆栽**——设定未写；③ **药炉带饕餮/云雷纹浮雕**，炉火是 **紫蓝**（设定写"青紫"，方向一致但偏蓝）；④ **虎皮上没有话本子**（剧本要求开场虎皮上散着七八本话本）；⑤ **石碑高大**，碑面字不可读（P02 卡要求四字可读）。 |
| 建议绑定范围 | 用途：`地理`（控制：峰体悬空关系、三间茅草屋朝向、药炉与云榻与石碑的相对位置、药田方位、云海高度）；不得控制：人物长相、具体镜头构图、炉火颜色以外的光比。副槽用途：`风格`（控制：暖金调、云海质感、CG 渲染颗粒）；不得控制：人物与服装。 |
| 挂图顺序 | 场景镜：①本图（第 1 格，地理）；人物镜：①人物身份板 → ②本图（第 2 格，地理） |

**需要回写设定的变化（以图为准）**：新增「瀑布」「石阶与木栏杆」「药炉浮雕纹饰」；炉火记作紫蓝。

## 2. 洛洛（5岁）身份板 · `ref-c01-luoluo.png`

| 项 | 结论 |
|---|---|
| 分类复核 | **判定为 人物形象 类**。理由：左侧大肖像 + 四视图 + 三格表情 + 头部细节 + 色板，全部服务于"这张脸/这套造型是谁"；含少量环境信息但不成体系，不另开环境槽。 |
| 色板采样（近似） | `#9CBFAE` 衫绿 · `#F2E8DB` 内衬米白 · `#3A2E2A` 发色 · `#D8B15A` 发饰金 · `#FFFFFF` 白底（与卡片色板一致，可复核） |
| 光位与硬度 | 摄影棚柔光：正面高位主光 + 两侧柔补，几乎无硬阴影；面部高光在鼻尖与颧骨，皮肤半透光。 |
| 质感归类 | **CG 渲染**（半写实 3D 儿童向）：发丝成束可见、绒毛领纤维清楚、丝绸有柔和镜面反射；皮肤有真实毛孔与血色，不是塑料。 |
| 冲突点（与现有设定） | ① 发饰是**金色花枝簪 + 珠坠**，设定写的是"素银药草簪"；② 发型是**两个小丸子 + 两侧细垂辫**，设定只写"两个小丸子"；③ 鞋是**白色小短靴**，设定写"浅米色布面软云履"；④ 毛领是**领口一圈适中绒毛**，设定写"偏大、像偷穿大人衣服"；⑤ 外袍下摆有**米白百褶内衬裙**，设定未写；⑥ 腰间斜挎**浅棕小皮包 + 葫芦**，与设定一致，位置在左侧。 |
| 建议绑定范围 | 用途：`身份`（控制：脸型、杏眼、左眼下小痣、两个小丸子+垂辫、金色花枝簪、衫绿外袍与米白内衬、白短靴、斜挎皮包与葫芦）；不得控制：表情（表情由镜头决定）、构图、场景、姿态。 |
| 挂图顺序 | 人物镜：①本图（第 1 格，身份） |

**需要回写设定的变化（以图为准）**：发饰改金色花枝簪+珠坠；发型加"两侧细垂辫"；鞋改白色小短靴；毛领改"领口一圈适中绒毛"；补"米白百褶内衬裙"。

## 3. 小药身份板 · `ref-c04-xiaoyao.png`
