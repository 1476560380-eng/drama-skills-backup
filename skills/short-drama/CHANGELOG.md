# CHANGELOG · short-drama

三段式记录：改了哪些 / 优化了哪些 / 兼容性验证。

## 2.11.0 — 2026-10-25（MINOR：文件规则模板换资产卡 v3 + 生成脚本修 bug）

**依据**：`short-drama-image-prompts` 升到 3.0.0（五份资产卡案例定版），本技能里被套用的模板与生成脚本需同步，否则新项目还会生成旧版式。

### 改了哪些

- `templates/文件规则模板.md`（图片提示词.md 一节）整段换 v3：
  - 子模板改为 T-CHA / T-GRP / T-PRP / T-UI / T-LOC，并指向技能 v3 细则。
  - 删「空白档案卡」与「档案卡内出现文字」；左侧改为大字号姓名＋一行资料。
  - 新增：纯白底＋冷灰细线、4K 出图与像素预算、四视图一致性四句、表情裁剪下限、单行 HEX 色板、比例尺部位锚线、线稿四视图、画面内短标签政策、职业符号防护。
  - 渲染尾由 `PBR材质…octane render` 改为按质感口径二选一（CG 资产卡 / 实拍剧照感）；撤销强制负向尾 `distorted，blurry，text error，garbled text`（与 `exact_readable` 冲突）。
- `scripts/project_card.py`：冲突提示文案里硬编码的「留白档案卡」改成 v3 措辞；`kinds` 列表补 `T-GRP`，避免群像卡项目漏判。
- 新建 `VERSION`（2.11.0）与 `CHANGELOG.md`。

### 优化了哪些

- 模板与技能 v3 同源，新项目起手即 v3，不再需要手工回改。
- 项目卡生成的「设定图口径」冲突提示能正确点名五类子模板。

### 兼容性验证

- `scripts/selftest.py` 17 项全过。
- 在《锤爆世界》实跑 `project_card.py`，正常生成、待裁决为空（json 为 zh-CN，与规则一致）。
- 模板占位符 `{{PROMPT_LANG}}` 等 4 处保持原样，生成路径未变。
- IMG 编号、镜像文件规则、分镜字段均未改动。
## 2.12.0 — 2026-10-25（MINOR：文件规则模板补齐三类卡分工与场景板禁忌）

### 改了哪些

- `templates/文件规则模板.md`（图片提示词一节）新增四条，与技能 `short-drama-image-prompts` 3.1.0 对齐：
  1. 三类卡分工：人物/道具＝棚拍资产逻辑，场景＝实景光逻辑；对齐质感语言，不对齐亮度分布。
  2. 场景卡光线口径：同一套光源＋允许视角与距离衰减、每格各自平衡曝光，禁止把暗区洗成平均亮；明确不要写「四格亮度一致」。
  3. 场景卡版面禁忌：纯四等分，不加底部细节条，不写名称/用途文字条。
  4. 参考用图纪律：四宫格只给人看，挂参考用单视角干净图、一镜一图。

### 优化了哪些

- 新项目起手生成的《文件规则》就带场景板口径，不用再靠事后补丁。
- 三条实测失败（标签污染、拉平亮度、上四下二版面）变成模板里的硬约束。

### 兼容性验证

- `scripts/selftest.py` 17 项全过。
- 模板占位符 `{{PROMPT_LANG}}` 等未动；生成路径不变；已存在的项目规则不受影响（下次生成项目卡时按模板重出）。
