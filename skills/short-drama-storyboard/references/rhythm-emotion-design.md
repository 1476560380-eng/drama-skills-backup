# 节奏与情绪设计

分镜的节奏不只是一堆镜长的平均值：情绪曲线的形状、段与段之间的反差、声音作为
节拍器，都是可以在分镜阶段显式设计的东西。本文档把这些设计工序集中起来，
全部为 `craft_default`：是有戏剧理由时可以调整的起步方法，不是阻断性规则，
也没有任何数值或题材映射是跨项目通用的验收条件。

## 先画曲线，再分镜

进入逐镜设计之前，先为本集画一条情绪强度曲线：横轴是全集时间，纵轴是情绪强度。
这一步的产出不进交付文档，但它的**决策**要落到 SEG 段落的情绪基调字段里。

1. 通读剧本，标出情绪节点：峰值（爆点/反转/顶点）、谷值（最低落/压抑锚点）、
   静默蓄力点（峰值前把观众按住的那一小段）。
2. 画出本集的曲线形状——形状由剧本和题材决定，不套模板。
3. 给每个 SEG 定节奏定位（见下节），检查相邻段的反差是有意设计还是碰巧。
4. 曲线上每一段的镜长目标回到 [镜长从哪来](shot-craft.md#镜长从哪来-sht-28)
   的机制推导；曲线只回答「这段相对全集是快是慢、为何如此」，不直接给秒数。

## 情绪曲线形状库（示例，不是规定）

以下是几种常见题材的曲线**形状**，用来说明「曲线可以长什么样」，不是任何项目
的答案。实际曲线必须从当前剧本画出来；题材相近也不代表形状可以直接套。

| 题材倾向 | 曲线形状 | 特征 |
|---|---|---|
| 逆袭/爽感 | 低开 → 蓄力 → 突然炸裂 → 逐级抬高的多个峰 → 收口 | 峰值递增，每一峰比上一峰高 |
| 悬疑/惊悚 | 钩子高位进入 → 回落缓渗 → 锯齿式小起伏 → 尾段大反转 | 峰在尾部，前段靠锯齿维持张力 |
| 温情/治愈 | 平稳日常 → 微澜 → 触动 → 缓缓收口 | 全程波动幅度小，靠细节而非落差 |
| 群像/多线 | 每条线各自一条小曲线，剪辑点在交叉处 | 单段形状服从该线人物，交叉点即切场 |

写曲线时问自己：本集最强的那一下在哪一分钟？它之前的三分之一是不是一直在
为它蓄力？如果全曲线是平的或处处是峰，问题在剧本层，不在分镜层，回到
`$short-drama-write`。

## 段间反差设计

**快是为了让慢更慢。** 一集里快切段和慢板段的反差本身就是叙事手段：受挫段的
密集快切，是在为后面的慢镜仪式感抢时间；反过来，收口段的长镜之所以有分量，
是因为前面切得够快。全片一个速度的「平均节奏」是最常见的浪费。

- 每个 SEG 段落头可加一个可选字段「节奏定位」，取值参考：`快切`（压缩、受挫、
  蒙太奇）/ `工作节奏`（对白、推进）/ `慢板`（情绪锚点、留白）/ `收口`（结尾谢幕）。
  写了就要能说出它与相邻段的反差意图。
- 慢板和收口不等于长镜堆砌：SHT-28 的镜长机制照常工作，慢板段的镜长仍由
  声音事件和留白需求推出，不是机械加秒。
- 一集里慢板段通常只有一两处：它是刹车，处处刹车等于没有刹车。哪里刹车
  由曲线上的谷值和情绪锚点决定。

## 声音作为节奏工具

分镜的「声音」行不只用来估对白时长；声音是最便宜的节奏工具，在分镜阶段标注，
剪辑阶段（`$short-drama-edit`）直接消费。

### 声音节拍器

- **静音蓄力**：情绪爆点前安排一小段绝对静音（约半秒内，具体长度是剪辑决定），
  在「声音」行标注 `【绝对静音】`。爆点越重，前面的静音越有价值；不是每个
  爆点都需要，一集两三处最有效，处处静音等于没有静音。
- **声音先入（J-cut）**：下一场的标志性声音在本镜末尾先进来（脚步、敲门、
  机械声），标注格式 `音效：XXX（先入）`。用于转场抢节奏或提前制造不安。
- **声音减法**：情绪锚点段不做加法——剥掉音乐，只留心跳、呼吸、环境底噪。
  在 SEG 段落头写一句「声音做减法」即可，具体的音轨处理属于剪辑阶段。
- **声音延续（L-cut）**：本场的对白或音效延续到下一镜画面上，对白拆镜时
  天然产生这个效果，在「声音」行注明即可。
- **叠声渐进**：紧张段把多个音效逐层叠上，压到极限再释放。属于剪辑层的
  手法，分镜只需要在该 SEG 标注「叠声渐进」让下游知道这是设计意图。

### 音效标注规范

音效独立成行或独立列出，不混入对白；多个音效用顿号分隔。系统音、广播、
电子音等非人声台词用【】标注来源，如 `【电子音：……】`，与配音指令
（角色｜音色｜状态｜语速）分开。这些格式约定与 `$short-drama-video-prompts`
和 `$short-drama-edit` 的输入习惯一致，写清即下游免翻译。

## 爆点递进原则

一场里安排多个连续爆点时，**逐级放大，最后一下最强**。每一级「放大」的载体
由题材决定：逆袭戏可以是资源→地位→命运；悬疑戏可以是线索→怀疑→真相；
温情戏可以是回忆→触动→和解。skill 只要求递进关系成立——第二峰不比第一峰
高时，问它是真爆点还是节奏噪声；不是爆点就降级为普通节拍，别给它峰值待遇
（静音蓄力、冲击强调、最慢的镜长都不给）。

## 三种蒙太奇压缩配方

蒙太奇是压缩时间的手段，镜头规则照常适用：每镜一个职责、边界可执行、
切镜带来变化。配方是起步方法，不是配额。

### 画外音 + 蒙太奇

背景交代、世界观铺设的默认压缩法：VO 短句断句推进，每句落一次画面切换。
成立条件：VO 的信息密度确实需要画面接力（每句画面都在推进信息，而不是
给 VO 配空镜）。15–25 秒量级是常见尺寸，不是规定。边界：每镜仍要写清
来源与起止状态，VO 文本属于剧本层，分镜不代写。

### 块切蒙太奇

受挫、训练、等待、重复劳动的压缩法：多镜硬切，**每镜一个独立的失败或
动作节点，不重复**——两镜都写「挖沙落空」就是重复，第二镜必须换节点、
换角度或换后果。音效接力推进（动作音一个接一个），该段不进旋律。
段末可以用一处静音蓄力接崩溃台词或转场。

### 声画对位

温柔的音乐配残酷的画面、明亮的画面配不祥的声音——反差制造「表面下的刺」。
这是三层视角（真实逻辑 vs 表面）在视听层的对应物：观众耳朵听到一个答案，
眼睛看到另一个。分镜只需在 SEG 标注「声画对位」并写明两侧各是什么；
音乐选择属于剪辑阶段。

## 防串味自检

本文档的每条规则在写进任何项目前过一遍：

- 这条规则换一个题材还成立吗？只对单一题材成立的内容属于项目层答案，
  应写进该项目的《视觉设定.md》或节奏档案，不进分镜。
- 色彩-情绪映射（什么颜色代表什么情绪）是**每个项目开工时自己定**的，
  定在《视觉设定.md》；分镜只负责段内口径一致、段间翻转有叙事动机
  （见 [光的设计](lighting-craft.md)）。
- 曲线形状是从当前剧本画出来的，不是从形状库抄的。
- 爆点递进的载体、静音的位置、蒙太奇的节点内容，全部来自剧本事实，
  不为满足「有设计感」发明剧本里没有的节拍。
