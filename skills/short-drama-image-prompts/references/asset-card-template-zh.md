# 中文商业设定卡模板（zh-CN 卡片式提示词）

当项目 `short-drama.json#/format/prompt_language` 为 `zh-CN` 且创作者选择「商业设定卡」风格时使用。来源：用户提供的《单独猎刀 道具设定卡》参考格式（2026-10-23），在《阈限空间》项目 22 个条目上落地验证。

## 四个子模板（按资产类型选择，不硬套）

| 模板 | 适用 | 版式核心 |
|---|---|---|
| T-CHA 角色/怪物卡 | 人物、怪物 | 左主立绘+空白框档案卡 / 中四视图 / 右表情或特征拆分+HEX色板 / 底动态+Line Art |
| T-PRP 道具卡 | 单道具、道具组 | 左主立绘+空白框档案卡 / 中四视图或多视图 / 右微距特写+色板 / 底挂载示意+比例尺 |
| T-UI 界面板 | 系统 UI | 单帧正视主图 + 状态对照小图；文字政策 readable 逐字列出 |
| T-LOC 四分格 | 场景、场景状态 | 16:9 四等分展示同一母场景四视角，固定地理 100% 统一；氛围关键帧可退化为单帧+小图 |

## 结构骨架（每条 IMG 的可复制正文）

1. 【全局规格与画幅】+ 绝对防合图规则（画面中只允许 X 这一个独立资产）
2. 【本体锁定】1:1 资产锁定，逐条列识别锚点（关键特征注明"三缺一不可"级权重）
3. 【版式排布】分区描述：左侧主立绘+档案卡、中间视图组、右侧特写+色板（HEX）、底部动态+线稿
4. 【负向提示词】逗号分隔，含：合图、第二人物、锚点丢失项、档案卡内出现文字、文字乱码、水印

## 硬规则

- **档案卡一律留白框**：画面内档案卡区域纯留白不渲染文字，档案信息（姓名/归属/用途）写在提示词外的「图外标注」行——防止模型生成乱码文字。创作者 2026-10-23 确认。
- **色板必给 HEX 值**，每资产 4-6 色。
- **局部资产（如只露爪肢的怪物）**用 Partial Sheet：把"身体不入画"写成设计约束而非残缺，负向词禁止"完整身体露出"。
- **UI 板是唯一 readable 特例**：逐字列出界面文字，负向词含"额外文字行、文字乱码"。
- 状态变体卡必须写【基准锁定】+【本状态差异（逐条对照）】，负向词含"基准脸变化"。
- 正文语言跟随 `prompt_language`；切语言要同步改 `short-drama.json`。

## 落地注意

- 重写既有 `图片提示词.md` 时，**IMG 编号与《标题》逐字保留**，否则分镜的`图片提示词项`引用全部断链。改完用脚本核对分镜引用的每个 `IMG-...《...》` 都能在图片提示词文件中找到同名二级标题。
- 每个 EP 目录下 `EPxxx图片提示词.md` 与 `图片提示词.md` 是镜像，改一个必须 cp 同步另一个。
