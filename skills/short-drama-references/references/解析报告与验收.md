# 解析报告格式与验收判据

## 报告结构（`输入/参考图/解析.md`）

文件头写清依据，避免报告过期无人知：

```text
> 依据：视觉设定.md 于 2026-10-25 12:51 生成；本报告基于此版本解析。
> 观察状态：实际看过图 / 未验证（标注到每张图）。
```

每张图一节，六项不缺：

| 项 | 写什么 | 常见错法 |
|---|---|---|
| 分类复核 | 「判定为 画风 类，理由：画面信息主要是色彩关系与光比，无明显角色与专有场景」 | 只写结论不写理由，创作者无法复核 |
| 色板采样 | 4–6 个近似 HEX，配中文色名 | 把单个颜色当色彩关系；不标「近似」 |
| 光位与硬度 | 主光方向、硬软、有无补光、光比 | 只写「氛围感很好」 |
| 质感归类 | 胶片颗粒 / CG 渲染 / 笔触 / 实拍 | 用「电影感」这种空词 |
| 冲突点 | 与本项目画风句、HEX、视觉设定直接冲突的地方 | 报告里只写优点，冲突留给下游撞车 |
| 建议绑定范围 | 用途 + 控制 + 不得控制 + 挂图顺序 | 写「全参考」 |

## 挂图顺序（创作者在项目外出图时必写）

```text
挂图顺序：①输入/参考图/style-anchor-01.jpg（第 1 格，风格）→ ②本卡文本（身份锚点）
```

顺序有影响：多数工具第一张权重最大，锚图务必放第一格。

## 验收判据（A/B 用，可被创作者推翻）

| 类别 | 验什么 | 判据 |
|---|---|---|
| 画风锚 | 场景定调图 A/B | 色彩关系同族、暗部处理一致、质感颗粒一致；用中性灰身份板验画风 = 验错对象 |
| 人物锚 | 身份板 A/B | 三视图是否同一人、关键锚点是否全中、负面词是否压住了漂移 |
| 环境 / 道具 / 动作 | 可合并一次验证或跳过 | 环境验地理锚点与光位；道具验形制识别点；动作验定格姿态能否被单帧承载 |

## 观察边界

- 看过图：可以报「画面右上有一处水印」这类实际可见事实。
- 没看过图：写「未验证」，不得推断水印、文字、裁切或身份。
- 负面提示词擦不掉参考图已有的像素——图里有不需要的元素，先换图或裁切。
