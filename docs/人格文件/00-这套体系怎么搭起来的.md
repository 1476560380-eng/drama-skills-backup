## 一、五个层次，各管一件事

| 层 | 存在哪 | 管什么 | 谁在改 |
|---|---|---|---|
| ① 技能层 | `~/.hermes/profiles/duanju/skills/short-drama-*`（12 个技能） | 「怎么写」——通用方法、字段契约、审查口径 | 升级技能，所有项目受益 |
| ② 项目层 | `锤爆世界/项目开发/`（文件规则、项目卡、逻辑校验清单） | 「这个项目怎么落地」——本剧特化口径 | 只本剧生效，不污染技能 |
| ③ 生成器层 | `项目开发/gen_containers.py`（325 行） | 「重复劳动自动化」——分镜 → 多镜容器 | 改生成器重跑，不手改产物 |
| ④ 产物层 | `剧集/EP001–EP005/`（每集 6 个 md） | 剧本、分镜、图片提示词、视觉设定、容器×2 | 生成器 + 人工修订 |
| ⑤ 版本层 | `~/drama-skills-backup`（git 仓库） | 每个改动有版本号 + CHANGELOG + tag | 每次改完必发版 |

分层的意义：**技能说通用方法，项目说本剧口径，生成器说重复劳动，版本层保证可回滚。** 四者不互相顶替，所以升级技能不会改坏旧本子。

```

        │  （拆集，规范化台词与场景）
        ▼

        │  （逐场拆镜、写意图与运镜理由）
        ▼

        │  ├─ 抽【冻结关键帧提示词】──► 图片提示词.md（出图用）
        │  └─ 读视觉设定取资产名 ──► 多镜容器提示词-15秒包.md（给生成软件）
```

**关键约束：下游只读上游，不许反向手改。** 容器里出现要改的内容，改分镜再重跑生成器；否则下次重跑就被覆盖，且两边永久不一致。

## 三、生成器做了什么（`gen_containers.py`）

它把「手抄 20 个镜头的固定句」变成一条命令，产出的每一包都必须带：

1. **切包**：单包 ≤15s、不跨 SEG（场景/色调不混）、尾包 ≥4s；
2. **风格块**：取首镜「Horizontal 16:9 质感锁」原文，段头色调只作块外一行说明（不叠进可复制块，防 mid-key 与 low-key 打架）；
3. **固定禁止项**：`禁止出现字幕，禁止出现背景音乐，禁止出现水印`，由代码常量 `BAN` 唯一出口；
4. **逐镜【镜头参数】**：从分镜 `Shot on …` 句逐字抓，不转述；
5. **时间锚**：`本镜 Xs（本包 Ys 中的 a–bs）` + 包级硬切声明；
6. **位置承接**：按英文首帧里的人名归属拆成中文句，空镜写「无人物」；
7. **人物映射**：视觉依据 ∪ 英文首帧点名，对不上视觉设定的自动打 ⚠️ 兜底；
8. **去元话语**：「本版/理由/本镜职责」这类话不进容器，留给剪辑看分镜。

命令：

```bash
python3 项目开发/gen_containers.py EP001 --write
python3 项目开发/gen_containers.py EP001 --src 剧集/EP001/分镜-搞笑夸张版.md \
        --out 多镜容器提示词-15秒包-搞笑夸张版.md --write
```

## 五、踩过坑才定下来的四条硬规矩

1. **先备份再改**：改前手动备份到 `备份/<事项>-<日期>/`，脚本改动另有 md5 检测自动备份。
2. **改一处、重跑全部**：口径（如禁止项、时长规则）只改生成器常量，然后五集全部重跑，不允许逐集手改。
3. **机器审计胜过口头确认**：说「写得不规范」不算数，先跑统计取证（例如「58 帧里镜头词出现 0 次」），拿数据说话再动手。
4. **发版三件套**：`VERSION` + `CHANGELOG.md`（改了哪些/优化了哪些/兼容性验证）+ git tag push。
