# 短剧创作系统使用说明书

> 适用：Hermes duanju profile · 11 个 short-drama 技能（官方全套 + storyboard 升级版）
> 项目根目录：`~/duanju/` · 当前活跃项目：《末世选择》

---

## 一、一句话理解

这套系统把短剧/漫剧创作拆成 **11 个各管一段的技能**，像剧组一样分工。
你对我说人话，我自动调对应技能；**不用记命令**，说清楚想干什么就行。

## 二、系统全貌（创作流水线）

```
小说/点子 ──→ ①novel-analyze ──→ ②develop ──→ ③write ──→ ④assets ──→ ⑤image-prompts
                 (拆原著)        (开发立契约)   (写剧本)   (拆视觉资产)   (图片提示词)
                                                                          │
成片 ←── ⑨edit ←── ⑧produce ←── ⑦video-prompts ←── ⑥storyboard ←────────┘
        (剪辑)      (付费生产)      (视频提示词)        (分镜+关键帧)
        
        ⑩review 全程可插（审任何阶段，只报问题不改文件）
        ⑪short-drama 总调度（建项目/看进度/跨阶段路由/机械核对）
```

**核心铁律：**
- 创作类技能只写文档，**不生成媒体**
- `produce` 是唯一花钱的环节，**每次都必须你明确点头**，预览/预算说明/既往确认都不算
- 五份核心文档是唯一真相：`剧本.md`、`视觉设定.md`、`分镜.md`、`图片提示词.md`、`视频提示词.md`

## 五、分镜技能（升级版）特别说明

你部署的 storyboard 是定制升级版，比官方多四样，**默认开启**：

| 增强项 | 给你带来什么 |
|---|---|
| 镜头技术捕捉 | 每镜三拍式笔触（起幅→运镜意图→落幅交接），分镜可直接指导生成/拍摄 |
| 配音指令 | 有对白的镜逐句标 `角色｜音色｜状态｜语速`，攒起来直接喂 TTS |
| SEG 段落 | 每 3–5 镜归段写情绪+色调，防逐镜生成画风漂移 |
| 镜长 0.5s 精度 | 对白镜先按发声时间估，节奏更准 |

说「这集分镜精简模式，不要增强规格」可整组关闭。

## 八、约定与边界

- **你只管创作决定**：画风、集长、目标模型、接受/拒绝节奏档案——系统只在你确认后落档
- **文档是唯一真相**：对话里的草稿不算数，以 `剧集/<EP>/` 里的文件为准；你说「剧本已确认」指的是文件，不是聊天记录
- **改动可追溯**：拆镜/并镜保留未受影响的镜头 ID；要刷新哪些下游文件会说清楚，但不自动改你没点名的文件
- **审查不改稿**：review 只出问题清单和修订要求，动笔改永远由对应负责技能执行
